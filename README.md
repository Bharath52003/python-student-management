# Student Management System using Python

## 📌 Project Overview
The Student Management System is a simple, menu-driven Python application that helps users manage student records. It allows users to add new students, view all student details, search for a student using their ID, and delete student records.

This project is developed using basic Python concepts and is suitable for beginners who want to improve their programming and problem-solving skills.

## ✨ Features
- **Add Student:** Add a student with an ID, name, and age.
- **View Students:** Display all registered student records.
- **Search Student:** Find a student using their unique ID.
- **Delete Student:** Remove a student record using their ID.
- **Interactive Menu:** Choose operations through a simple command-line interface.
- **Input Validation:** Handles invalid menu choices and displays appropriate messages.

## 🛠️ Technologies Used
- Python 3
- Lists and Dictionaries
- Conditional Statements
- Loops
- User Input and Output

## 🚀 How to Run the Project

### Prerequisites
- Install Python 3 on your computer.
- Download or clone this repository.

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/python-student-management.git
   ```

2. Navigate to the project folder:

   ```bash
   cd python-student-management
   ```

3. Run the Python program:

   ```bash
   python student_management.py
   ```
